## 🎯 Quick Start (5 minutes)

### To Document Any Approach:

**Step 1**: Copy master prompt
```
cp APPROACH_DOCUMENTATION_MASTER_PROMPT.md [temp_file]
```

**Step 2**: Replace placeholder
```
Replace [APPROACH_NAME] with your approach name
Example: RCM, MACD_Crossover, etc.
```

**Step 3**: Submit to AI
```
Use the customized prompt with:
- Code base location
- Documentation goals
- Quality requirements
```

**Step 4**: Review deliverables
```
Check against quality checklist:
- 4 documents created
- Code accuracy verified
- Consistency confirmed
```

**Step 5**: Deploy
```
Place in docs/APPROACHES/[APPROACH_NAME]/
Share with team
```
