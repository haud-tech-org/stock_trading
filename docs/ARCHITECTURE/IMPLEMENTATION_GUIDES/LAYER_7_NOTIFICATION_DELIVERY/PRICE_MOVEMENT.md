# Implementation Guide Template: Layer 7 Notification Delivery Service


This guide documents how to implement and extend announcement-type approaches (e.g., Price Movement) in the new modular, type-based notification architecture. Use this as a reference for all announcement approaches.

---


## 1. Service Overview
- **Service Name:** Price Movement (or your announcement approach)
- **Purpose:** Detects price movements and generates announcement alerts, delivered immediately via enabled channels.
- **Scope:** Announcement-type approaches only (not trade signals).

---


## 2. Key Components
- **Alerter/Detector Class:** Implements business logic for the announcement (e.g., `PriceMovementAlerter`).
- **Factory:** Registers and instantiates approach classes (internal, not public).
- **Orchestrator Integration:** Only the orchestrator is public; it invokes the correct approach via the factory and delivers alerts to enabled channels.
- **Alert/Announcement Model:** Data structure used for notifications (e.g., `AlertData`).

---



## 3. How the Service Works
1. **Configuration:**
    - Each approach in `executor_approach_configuration.json` must specify an `approach_type` (e.g., `"announce"` for Price Movement).
    - Example:
       ```json
       "PRICE_MOVEMENT": {
          "enabled": true,
          "resolution": 1,
          "description": "Detects price movement and level crossings for alerts.",
          "approach_type": "announce",
          "approach_config": {}
       }
       ```
    - The orchestrator uses this field to route and process approaches correctly.
2. **Detection/Trigger Logic:**
    - The orchestrator uses the `ApproachType` enum and the `get_supported_approaches(symbol, approach_type)` method to filter and process approaches by type.
    - Announce-type approaches (like Price Movement) are handled in a dedicated announcement flow, separate from trade-type approaches.
    - Example code:
       ```python
     from src.stockreports.model.approach_type import ApproachType
     announce_approaches = ExecutorConfigurationOrchestrator.get_supported_approaches(symbol, ApproachType.ANNOUNCE)
     trade_approaches = ExecutorConfigurationOrchestrator.get_supported_approaches(symbol, ApproachType.TRADE)
     ```

3. **Alert Generation:**
   - Alerts are generated by the approach class (e.g., `PriceMovementAlerter`) and returned to the orchestrator.
   - Alert objects include price, time, and direction details.
4. **Notification Dispatch:**
   - Alerts are sent to the orchestrator, which delivers them immediately to enabled channels (no scheduling/reminders).

---


## 4. How to Extend or Modify
- **Configuration:** Add or change business rules in config (per approach, by `approach_type`).
- **Business Logic:** Implement a new approach class, register in the factory, and ensure orchestrator integration.
- **Integration:** Only the orchestrator is public; all approach logic is invoked via the orchestrator.

---


## 5. Code Locations
- Main logic: `src/stockreports/alert/announce/approach/PRICE_MOVEMENT/price_movement_alerter.py`
- Factory: `src/stockreports/alert/announce/factory.py`
- Orchestrator: `src/stockreports/alert/announce/orchestrator.py` (public entry point)
- Main alerting flow: `src/stockreports/alert/symbol_alerter.py` (handles both announce and trade approaches using type filtering)

---


## 6. Troubleshooting
- Common issues: missing configuration, no alerts generated, integration errors, or approach not registered in factory.
- Where to check logs and how to debug: orchestrator logs, approach logs, config validation.

---

## 7. Example: Price Movement Implementation
- **Business Logic:** Detects when a symbol's price crosses configured levels or intervals.
- **Configuration:** Set in the price alert settings for each symbol, with `"approach_type": "announce"`.
- **Alert Generation:** Creates `AlertData` objects with price, time, and direction details.
- **Notification:** Alerts are sent to the orchestrator for multi-channel delivery.
- **Type Filtering:** The main alerting flow uses `ApproachType` to ensure Price Movement is processed as an announcement, not a trade signal.
