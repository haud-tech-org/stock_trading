## 📊 WHAT THE ASC APPROACH DOES

### Detects REVERSAL Signals
Identifies when a strong price trend is likely to reverse based on:
- Abnormal candle volatility (Anchor Candle)
- High-volume confirmation (Signal Candle)  
- Price extremes + wick validation (Alert Candle)

### Signal Generation
```
IF original trend = UPTREND → Generate SELL alert (reversal down)
IF original trend = DOWNTREND → Generate BUY alert (reversal up)
```

### The 4 Validation Steps
```
1️⃣ Window Size & Trend    - Is window large enough? What's the trend?
2️⃣ Anchor Candle          - Is there abnormal volatility?
3️⃣ Signal Candle          - Is there high volume confirmation?
4️⃣ Alert Candle & Wick    - Does final candle show reversal pattern?
```
